# WS WAN LED: status 2026-11-01 (already SOLVED and FLASHED)

The WAN LED issue was diagnosed with the user watching and fixed on 2026-10-31.
The fixed image is installed (flashed 2026-10-31 23:16, again 2026-11-01 00:12
with the fan/ksmbd build).

## Findings (tested live with the user)
- Each socket: right LED = 2-pin bicolor between PHY LED[0] (green) and LED[1]
  (orange); left LED = green only on LED[3]; LED[2] not wired.
- WAN socket: LED[0] (green) is NOT wired, only orange. With the default
  0x1777 the right LED stayed dark at 1000 Mbit (mode 7 = orange below 1G).
- The stock LaCie kernel writes the same 0x1777, so the WAN right LED was
  never green there either (hardware).
- LED[1] modes on this PHY: 0/5 off, 1/2 link+activity, 3/4 activity only,
  6 link at 100/1000 (steady), 7 link below 1000.
- Fix: DTS reg-init for PHY 6 only: page 3 reg 16 = 0x1767 (LED[1] mode 6):
  right WAN LED steady orange with link at 1000 and 100 Mbit (user confirmed
  both). 10 Mbit untested (far end has no 10M).
- Left LED cannot be orange (green-only LED).
- Do NOT write page 3 reg 18: 0x4100 there dropped the WAN link for ~12 s.
